# Changelog

## v1.0.0 — September 2026: the audit release

The September 2025 artefact (`Yuchiwang02/DelaySentinel`) was a bare Hugging Face model
repo with a Flask app and a README that had no metrics. This release turns it into a
reproducible case study. Nothing about the weights changed; everything about how they
are described did.

### Findings that drove the rewrite

- The Kaggle label is a deterministic two-field rule (`Shipment_Status == "Delayed" OR
  Traffic_Status == "Heavy"`, 1,000/1,000 rows). The published model's 100% test
  accuracy is a measurement of that rule; a depth-2 decision tree scores the same.
- Counterfactual probes show the model behaves as that rule (all edits to the rule
  fields flip the prediction; edits to other fields do not), and it emits a confident
  label on prompts outside its schema.
- The original repo violated the Llama 3.2 Community License (declared `apache-2.0`, no
  agreement copy, no "Built with Llama", no "Llama" prefix in the name) and did not
  attribute the training script (a copy of `acon96/home-llm`'s `train.py`, MIT).

### Fixed

- **Licence and naming.** `LICENSE` (Llama 3.2 Community License), `USE_POLICY.md`,
  `NOTICE`, `THIRD_PARTY_LICENSES.md`; front-matter `license: llama3.2`; "Built with
  Llama" on the card; repository renamed to `Llama-3.2-1B-DelaySentinel`.
- **Attribution.** `scripts/train.py` carries its upstream header (commit `d352d88`,
  MIT) and lists the local changes.
- **Model card.** Rewritten around the leakage disclosure; every number is generated by
  `python -m delaysentinel.eval` and checked by `scripts/check_card_numbers.py` in CI.
  Removed: the non-existent Gradio Space claim, the placeholder repository link, the
  wrong repo id, the invented `<|system|>` prompt format, the foreign example schema,
  "AI-powered", "before shipment", "order-level".
- **Metadata.** `base_model` → `meta-llama/Llama-3.2-1B-Instruct`; `pipeline_tag` →
  `text-generation` (the checkpoint is a causal LM); `library_name: transformers`.
- **Decoding config.** `generation_config.json` is now greedy with `max_new_tokens: 8`
  (it shipped with the base model's sampling defaults); `config.json` `use_cache` is
  `true` again (training left it `false`).
- **Inference code.** The Flask app (local model path, `<pad>` token added and embeddings
  resized at inference, 512-token generation, `includes('1')` parsing, form asking for
  the *delay reason* before predicting the delay) is retired to `legacy/`. `src/` uses the
  tokenizer's own `<|finetune_right_pad_id|>`, greedy decoding and an anchored regex; an
  unparsable answer is counted, never mapped to 0.

### Added

- `src/delaysentinel/`: prompt utilities, frozen-split loader, metrics with Wilson /
  Clopper-Pearson / bootstrap intervals, six baselines, counterfactual / robustness /
  out-of-distribution probes, teacher-forced label scoring, CSV→JSONL transform, a generic
  leakage scanner, the case-study figures.
- `results/eval.json` and `results/test_predictions.csv` (per-row predictions),
  `results/leakage_audit.json`.
- `data/SPLIT.md` (hashes and the reasons the split is frozen), `runs/RUNS.md` and the
  three runs' `training_config.json` / `trainer_state.json`, including the eval-subsample
  and pad-mask quirks inherited from the upstream trainer.
- `tests/` (pytest, no model download) and a GitHub Actions workflow that also runs the
  README number check and a baselines-only evaluation.
- `space/`: a Gradio demo whose point is to show the rule, not to predict delays.
- `docs/case_study.md` (English) and `docs/case_study.zh.md` (中文).

### Not changed on purpose

- The weights, the frozen `train.jsonl` / `test.jsonl`, and the `training_args.bin` in the
  model repo. The historical split stays unseeded and un-replayable; it is hashed instead.
- No re-training, no new dataset, no claim of predictive value.
